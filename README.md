# DRIGHT
Worldwide marketplace and social-commerce platform.

## Phase 0 — Checkpoint 1
Foundation: Next.js + TypeScript, Tailwind, Supabase clients, theme architecture, internationalization foundation, currency foundation, and AI-provider boundary.

## Run
npm install
npm run dev

Copy `.env.example` to `.env.local` and add the Supabase URL and publishable key.

Business rules are implemented incrementally and confirmed before major systems are built.
